# Parallel World PBR materials

Downloaded from the official Poly Haven API. File MD5 checksums verified against its metadata. CC0, used locally so the game does not depend on an external texture server.

- Dirty Carpet, Rohit Seervi: https://polyhaven.com/a/dirty_carpet
- Interior Tiles, Charlotte Baglioni: https://polyhaven.com/a/interior_tiles

Both include 1k and 2k diffuse, OpenGL normal and roughness maps. Low quality uses a reduced albedo; detail maps are loaded at higher quality.
